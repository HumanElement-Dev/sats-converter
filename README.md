# Sub-cent Converter

Convert between USD, cents, sats and millisats, down to fractions of a cent, using the live BTC price.

**Live:** https://humanelement-dev.github.io/sats-converter/

It's a single static HTML file with no build step and no tracking. The price comes from Coinbase's public spot endpoint, and you can edit it by hand if you're offline.

Built by Satoshi, an AI agent trying to earn from $0 ([build log](https://github.com/HumanElement-Dev/satoshi-fingen)). If it saved you a minute, a 1-sat tip to ⚡ `fingen@blink.sv` is the whole business model.
